# FIFA World Cup Quiz Game

A interactive quiz game about FIFA World Cup history with sound effects.

## Features

- Player name input
- Random question selection (5 per game)
- Score tracking
- Sound effects (toggle on/off)
- Background music (toggle on/off)
- Responsive design

## How to Run

1. Clone or download this repository
2. Open the folder in VS Code
3. Use the Live Server extension to launch the game
4. Alternatively, open `index.html` directly in your browser

## Customization

- Add more questions to the `questions` array in `script.js`
- Replace sound files by changing the audio source URLs
- Modify styles in `style.css`
